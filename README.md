# Sun City Epoxy Flooring

Source for suncityepoxyflooring.com. Pages are generated by `src/build.mjs` into `public/` and served by a Cloudflare Worker (`worker/index.js`), which also receives the estimate form at `/api/lead`.

## Pages

- `/`
- `/garage-floors/`
- `/interior-floors/`
- `/slip-resistant-flake-floors/`
- `/metallic-floors/`
- `/one-day-floor-coatings/`
- `/patio-coatings/`
- `/business-floors/`
- `/about-us/`
- `/neighborhoods/`
- `/contact/`
- `/privacy-policy/`

Service pages live in `src/content/services/` (one file per page, registered in `src/site.mjs`).

## Working on it

```
npm run build
npm run deploy   # build + wrangler deploy
```
